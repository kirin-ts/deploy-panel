# DeployPanel · 开源项目一键部署面板

本地面板：**GitHub 搜索项目 → 自动识别许可证与作者限制（中文解读）→ 强制 GPL 律师审核 → 自动匹配环境 → 一键下载部署 → 环境打包带走**。全程数据在本机，核心能力可离线运行。

## 快速启动

```bash
# 在项目目录下执行
python server.py
```

然后浏览器打开 **http://127.0.0.1:8787**

（也可双击 `start_面板.bat` 一键启动并自动打开浏览器）

## 功能

| 模块 | 说明 |
|---|---|
| 项目搜索 | 联网搜 GitHub（断网自动用本地缓存）；每个项目带许可证徽章 |
| 许可证识别 | GitHub 元数据 + LICENSE 文本双重识别；输出中文解读（能否修改/商用/闭源/是否必须开源） |
| 作者限制识别 | 自动扫描 README 中英文限制声明（禁止商用、仅供学习、禁止转载、需授权等）并翻译成中文警告 |
| GPL 律师审核 | 部署前强制：内置 GPL v2/v3/LGPL/AGPL 合规清单（离线知识库），输出风险分级 🔴🟡🟢 与合规检查项，生成中文审核报告落盘 |
| 环境自动检测 | 自动识别 Node / Python / PHP / Java / Go / Docker / .NET / 静态站点，给出启动命令与依赖清单 |
| 一键部署 | 生成「start_一键启动.bat」+ 部署配置，双击启动 |
| 运行状态开关 | 每个项目可一键**启动/停止**（一键开关），自动识别进程是否存活，停止时终止整个进程树 |
| 数据库可视化编辑 | 自动扫描项目内 SQLite 数据库，**不写代码**直接在界面增删改：添加行、编辑单元格、删除行、添加列、新建表 |
| 环境打包带走 | 导出 zip：项目代码 + 部署配置 + 启动脚本 + GPL 审核报告 + 中文使用说明 |
| 积木工作室（低代码） | 像搭积木一样写程序：从积木库拖拽积木到画布、点击连线成流程（顺序/条件/循环）、参数面板填值不写代码，一键**运行**（本机执行）或**导出独立 .py 文件**；程序员可用「＋自定义积木」提前写好代码模板注册新积木，也可改内置积木 |
| 应用搭建器（搭前后端） | **拖组件搭页面 + 一键生成真实前后端应用**：组件库拖入画布（标题/文本/输入框/表单/按钮/数据列表/导航等），属性面板改文案与绑定字段；自动收集表结构，生成 **Python 后端 + 页面前端 + SQLite 数据库** 的完整 Web 应用，独立端口**一键运行/停止**，页面可提交表单入库、数据列表展示；组件可自定义（程序员注册 HTML 模板） |

## 离线能力

- 许可证识别 / GPL 审核 / 环境检测 / 部署 / 打包：**全部内置离线**
- GitHub 搜索与仓库下载：需要联网；断网时搜索回退到本地缓存，审核仍可用
- 数据目录：`data/`（配置、搜索缓存、LICENSE 缓存、审核报告、部署记录、导出包）
- 已下载项目缓存于 `workspaces/`

## 安全与合规

- 下载的仓库代码**解压时防路径穿越**，只解压到本机 workspaces 目录
- 部署前 GPL 审核未通过（🔴）时**强制阻止部署**，需先阅读报告
- 使用本项目导出的任何代码前，请阅读「GPL审核报告.md」并遵守许可证义务
- 审核报告为信息性合规分析，不构成正式法律意见；重大决策请咨询执业律师

## 设置（可选）

GitHub 未登录状态下 API 限额较低（10 次/分钟）。可在「设置」填入 Personal Access Token 提高限额：
GitHub → Settings → Developer settings → Personal access tokens → Generate new token（勾选 `repo` 与 `public_repo` 权限），Token 仅存本机 `data/config.json`。

## 目录结构

```
deploy-panel/
├── server.py            # 本地服务（Python 标准库，零依赖）
├── app.html             # 面板界面（单文件）
├── gpl_kb/              # 离线知识库（许可证清单/合规规则/限制词库）
├── data/                # 运行时数据（自动生成）
│   ├── blocks_builtin.json    # 内置积木库（14 块）
│   ├── blocks_custom.json     # 自定义积木（程序员注册）
│   ├── flows/                 # 积木工程（保存的流程图）
│   ├── components_builtin.json# 内置组件库（10 个：标题/表单/按钮/列表等）
│   ├── components_custom.json # 自定义组件（程序员注册）
│   ├── apps/                  # 应用工程（页面组件树）
│   └── apps_runtime.json      # 应用运行记录（pid/端口）
├── workspaces/          # 已下载项目（自动生成）
└── logs/                # 运行日志
```

## 积木工作室使用说明

1. **拖积木**：左侧积木库按分类列出（流程/基础/文件/网络/数据库/高级/自定义），把积木拖到中间画布
2. **连线**：点击积木下方的圆点（出点）进入连线模式，再点击目标积木顶部的圆点（入点）完成连接；「如果…否则…」有右（是）左（否）两个出点，「遍历循环/条件循环」有右（循环体）出点
3. **填参数**：点击画布中的积木，右侧参数面板填写（不写代码）；参数面板里可删除该积木的连接
4. **运行/导出**：工具栏「▶ 运行」在本机直接执行并显示输出（可展开查看生成的 Python 代码）；「⬇ 导出 .py」生成独立可运行文件
5. **保存工程**：填工程名后「💾 保存」，之后可从下拉「加载工程」恢复；「＋ 新建」清空画布
6. **自定义积木**：「＋ 自定义积木」按提示填 id/名称/Python 代码模板即可注册；模板里用 `{key}`（裸值）或 `{key!r}`（安全字符串）引用参数

## 应用搭建器使用说明

1. **搭页面**：左侧组件库（基础/表单/数据/媒体/布局/自定义）把组件拖到中间画布；点组件在右侧属性面板改文案、绑定字段、动作；组件可「↑ ↓」调序、删除
2. **表单容器**：先拖「表单容器」再点选它，之后拖入的输入框/按钮会进入表单内；表单的表名即数据表名
3. **数据列表**：拖「数据列表」并设置要展示的**数据表**与**字段**（逗号分隔），生成后页面自动加载数据
3b. **外观与位置**：每个组件都有通用样式属性——**对齐**（左/居中/右）、**宽度**（默认/全宽/半宽）、**边框**（无/细/明显）、**圆角**（小/中/大）、**外边距（位置）**（小/中/大），生成页面同步生效
3c. **鼠标键盘操作**：画布组件可**直接拖动**调整顺序（拖到目标组件上方/下方松手）；选中组件后可用键盘 **↑↓ 调整顺序、Delete 删除**
3d. **栏折叠与预览**：工具栏「组件库」「属性面板」按钮可**收起/展开左右两栏**（画布空间随之扩大，双收起后画布占满）；画布上方可切换 **网页/手机** 预览比例（手机 375px 居中模拟）
4. **按钮动作**：点按钮设「提交到数据表」（需在表单内）、「提示消息」「打开链接」
5. **生成/运行**：填应用名 → 「💾 保存」→「⚙ 生成前后端」（自动建 SQLite 表、分配端口 8801 起）→「▶ 运行」→「↗ 打开页面」；「⏹ 停止」安全关闭（先优雅关闭再兜底结束）
7. **Logo/图片属性**：导航栏有「Logo 图片」、图片组件有「图片地址」属性，属性面板支持**上传本地图片**（保存到本机）或**线上下载**（填 http(s) 地址点「线上下载」自动下载到本机）；生成时图片自动复制进应用 `assets/` 目录，**离线也能显示**
6. **自定义组件**：「＋ 自定义组件」填 id/名称/HTML 模板（属性用 `{key}` 引用，自动安全转义）即注册
6b. **修改组件代码**：组件库每个组件卡片右上角 **✎** 打开代码编辑器——可随时改 **HTML 模板、CSS、属性定义 JSON**，实时预览后保存；内置组件改完即覆盖（可删除恢复默认），画布已放置的组件与新生成的应用同步生效（CSS 注入到画布与生成页面）
6c. **创建组件**：「＋ 自定义组件」直接打开代码编辑器填写（**组件 id 支持中文**，仅限中文/字母/数字/下划线/短横线；名称/属性标签等显示内容全部支持中文）；创建后立即进入代码编写，保存即出现在组件库
7. **按钮提交**：「提交到数据表」动作**自动使用所在表单容器的表名**（按钮需放进表单容器），属性面板有明确提示
8. **路由地图**：工具栏「🔗 路由地图」以**连线图 + 路由表**展示当前应用的全部数据流——前端组件（表单/按钮/数据列表）→ 后端接口（GET/POST /api/data/{表}）→ 数据表/跳转去向；「⚙ 生成前后端」时还会在应用目录写入 **templates/ROUTES.md** 路由说明（接口、数据表、前端触发清单），随应用打包可拷走
9. **一键运行预览**：点「▶ 运行」自动完成 保存→生成→启动，并在**新标签页单独打开模拟页面**（http://127.0.0.1:{端口}）直接预览与测试；停止后可点「↗ 打开页面」重新打开
9i. **下载来源标注（溯源）**：每次下载成功自动记录来源 URL 至 data/download_log.json（路径去重、最新 500 条），下载资源列表每条显示「来源: URL」（悬停可见完整地址），预览弹层同步展示；历史遗留文件标注「未记录（历史文件）」；删除文件时同步清理对应日志。
9h. **批量删除**：下载资源视图每条带勾选框，顶部「全选」一键勾选，「删除选中(N)」批量清理（红色警示样式，无勾选时禁用）；删除前弹确认框，支持删除文件与子目录，后端 /api/url/dl_delete 路径白名单校验（仅限下载目录内，禁止删根目录），完成后自动刷新并提示删除数量。
9g. **下载资源预览**：下载资源每条新增「预览」按钮，面板内直接查看——图片（png/jpg/gif/webp/svg…）弹层显示、视频（mp4/webm/mov/mkv/ts）内嵌播放器（后端 Range 支持可拖动进度）、音频内嵌播放、文本/代码（txt/md/py/js/json/csv/log…）等宽字体展示；Esc 或「关闭」退出。后端新增 /api/url/preview（路径白名单 + MIME 映射 + Accept-Ranges）。
9f. **下载资源导航视图**：侧边栏新增「下载资源」入口，独立页面集中管理全部下载产物（含图片下载、视频/文件直链、m3u8 合并产物），每条显示序号/相对路径/大小/下载时间，可「所在位置」在资源管理器打开；顶部汇总「N 个文件 · 共 X」，支持刷新与一键「打开下载目录」。
9e. **一键下载 + 进度条 + 下载管理**（网址分析器下载面板）：输入任意 http(s):// 地址（视频/图片/压缩包/任意文件）点「一键下载」；直链流式分块、m3u8 自动合并，**实时进度条**（直链按字节、m3u8 按分片，逐条更新百分比）；下方「已下载文件」列表显示全部产物（名称/大小/时间），每条可「所在位置」在资源管理器中打开，或「打开下载目录」直达根目录（路径白名单校验，仅限面板下载目录）。
9d. **视频下载**（网址分析器下载面板）：自动提取页面内嵌 `<video>`/`<source>`/mp4·webm·mov·m3u8·flv 直链并列出（V1/V2…），一键下载；也支持粘贴任意视频地址下载。直链走**流式分块写盘**（上限 300MB，不占内存）；**m3u8 流媒体自动解析分片清单并逐片下载、合并为 .ts**（分片加密 AES-128 时明确提示需 ffmpeg）；SSL 证书异常自动降级重试；文件存 workspaces/downloads/videos/。
9c. **安全检测 + 资源下载**（网址分析器内）：分析自动附带**钓鱼/恶意检测**（非 HTTPS、IP 直连、非常规端口、短链、仿冒知名域名 Levenshtein 变体、本地黑名单 data/phishing_blacklist.txt 可扩展；仿冒站点红色「危险站点」徽章并禁止下载）；页面图片一键勾选**批量下载**到 workspaces/downloads/，下载被拦截时**自动切换 4 套环境重试**（多浏览器 UA / Referer / Accept-Encoding 轮换），直到成功或全部尝试完毕，结果逐条显示「环境N」。
9b. **网址分析器**（原「积木工作室」改造）：输入网址 → 自动抓取并分析（标题/页面类型/robots.txt 合规检查/表格·列表·图片·链接统计/正文预览）→ 按页面结构**推荐爬取脚本方案**（简易抓取/表格 CSV/列表/JSON，标「推荐」）→ 一键生成可运行爬虫（首次运行自动安装 requests+beautifulsoup4）→ 面板内直接运行，产物（output_table.csv / output.json 等）写入 workspaces/crawls/；脚本可复制导出。合规提示：尊重 robots.txt，受限页面会明确标注禁止抓取。
10. **运行数据实时视图（可视化）**：运行后画布下方显示生成应用的**数据库实时数据**（表/列/行数/最新 5 行，可刷新），并支持**直接可视化编辑**——点击单元格改数据、＋ 行/＋ 字段/＋ 新建表、删除行/字段/整表，全部即时生效（改表结构后重新「生成前后端」页面才会同步显示新字段）；「📄 代码」按钮可查看并复制生成的 **app.py / index.html / ROUTES.md** 完整代码；路由地图每条流向带「✏ 改」按钮，可直接**修改路由指向**（数据表/字段/跳转链接/提示内容），改后画布、地图、生成代码同步更新

生成的应用为独立项目（`workspaces/apps/<应用名>/`）：`app.py`（Python 标准库后端 + `/api/data/<表>` 读写）+ `templates/index.html`（页面）+ `data.db`（SQLite），零第三方依赖、可离线运行，可直接拷走部署。

## 已知边界

- 部署执行的是「生成启动脚本 + 安装依赖命令」，需目标电脑预装对应运行时（Node/Python/PHP 等）
- 在线服务型（需数据库/账号体系）项目可能无法开箱即用，以项目 README 为准
- 运行状态开关支持静态/Node/Python/PHP/Java/Go/.NET（通过任务管理器终止进程树）；Docker 类型使用 docker compose up/down
- 数据库可视化编辑当前支持 **SQLite**（.db/.sqlite/.sqlite3，Python 内置无需安装）；MySQL/PostgreSQL 需连接串与驱动，暂未纳入
- 积木工作室的运行/导出在本机执行**真实代码**：内置积木模板为白名单且参数自动安全转义；「运行 Python 代码」「遍历对象/条件表达式」等积木接受自定义表达式，等同于运行自己的代码，请勿粘贴不可信内容
- 应用搭建器生成的应用在本机独立端口运行（本地面板仅作构建工具，不影响面板服务）；生成的数据写入 `workspaces/apps/<应用名>/data.db`；微信/抖音小程序形态需平台开发者工具与账号，可用生成的 Web 应用转导出
- 仅供学习与合规使用；请勿用于网游作弊等违法违规场景

- 功能使用说明与速查表见同目录 [GPL合规说明.md](GPL合规说明.md)。
